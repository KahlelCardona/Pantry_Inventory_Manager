# Pantry_Inventory_Manager

Project Vision statement

By creating a way to track groceries bought and helping users come up with recipes they’ll enjoy, we believe we can help users save money and waste less food.

project’s Concept of Operations

Project: Pantry/fridge food manager + recipe generator

Prepared by: Michael Haley, Kahlel Cardona, Mateusz Doda, Richard Alonso Garcia, Loleyi Oluwatomisin

Major Functions: barcode scanning, grocery management, recipe generator, and nutrition tracker
Operational Scenarios: A user scans/adds groceries, removes groceries, generates recipe ideas, adds liked recipes, and adds liked recipes into the system.
User Needs: Easy to use Interface, Integration with AI, food warnings, real time updates about expiration dates. 

Use Cases

A user scans new groceries using their barcodes
A user adds grocery information into a database
A user remove grocery information from a database
The system generates recipe ideas upon a users request
The system give warnings for potential allergies
A user adds recipes to Liked recipes
A user adds allergies to the system

Epics & User Stories
Epic 1: Create frontend for android app
As a developer, I want to create an app with pages (home page with ingredients, recipe page, scanning page) that will open to a scanning page (5 points)
As a user, I want to be able to view groceries that I currently have so I don't buy extra ingredients (1 point)
As a user I want to be able to view my liked recipes so that I can remake a recipe that I had in the past (1 point)
As a user I want to be able to add their allergies into the system so that I can see warning about recipes that I may be allergic to (1 point)
As a user, I want to be able to view nutrition on ingredients that I scan (1 points)
As a user, I want to be able to generate recipes based on ingredients I have (1 point)
As a user, I also want to be able to filter recipes (certain ingredients, ingredients I have/don’t have, allergies, dietary needs) (2 point)
As a user I want to be able to add items by barcode scan so I don’t need to type in ingredients. (5 points)
As a user I want to be able to add items manually with its name and quantity. (2 points)
Epic 2: Create database to store food information
As a user, I want to be able to see if food is expiring soon so that I waste less food (3 points)
As a user, I also want to be able to get push notifications of expiring food within 3 days (1 point)
As a user, I want to know where the food is stored (fridge, freezer, pantry) to keep track of where ingredients are (2 points)
As a developer, I want a database schema for ingredients, recipes, shopping lists, favorite recipes, and allergies (3 points)
As a developer, I want to be able to get information about groceries scanned in through barcode from the internet (3 points)
As a user, I want to be able to save favorite recipes to save time (2 points)
Epic 3: Recipe generator 
As a developer, I want to implement an AI tool and a prompt template to generate recipes based on user requirements. (5 points)
As a user, I want the recipe generator to prioritize expiring ingredients to save not have to throw it out (2 points)
As a user, I want to be able to choose recipes with ingredients I have without the need to get more ingredients (1 point)
As a user, I want to be able to choose recipes with ingredients I don’t have to have more options for meals (1 point)
As a user, I want to know how big serving sizes should be to be able to portion out servings for others or to save meals for later (1 point)
As a user, I want to be able to ask for recipes without certain ingredients (like salt or sugar) in case of a dietary need (1 point)
Epic 4: nutrition tracker
As a user, I want to measure the nutritional value of recipes to know if I’m meeting my daily needs (3 points)
As a developer, I want to be able to get data from the recipe serving sizes to be able to get exact nutritional value (2 points)
As a user, I’d want meal data to be added automatically according to the serving sizes to save time (2 points)
